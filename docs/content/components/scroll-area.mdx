# Scroll Area

Augments native scroll functionality for custom cross-browser styling without layout shift. Built on Base UI ScrollArea primitives.

<div className="flex flex-wrap items-center gap-2 my-4">
  <Badge variant="outline" className="font-mono text-[11px]">@base-ui/react</Badge>
  <Badge variant="secondary" className="font-mono text-[11px]">Zero Layout Shift</Badge>
</div>

## Import

<CodeBlock language="tsx" code={'import { ScrollArea, ScrollBar } from "@galaui/react";'} />
