# Preview Card

Rich preview popup displayed on pointer hover for link previews or user cards. Built on Base UI PreviewCard primitives.

<div className="flex flex-wrap items-center gap-2 my-4">
  <Badge variant="outline" className="font-mono text-[11px]">@base-ui/react</Badge>
  <Badge variant="secondary" className="font-mono text-[11px]">Hover Card</Badge>
</div>

<CodeBlock language="tsx" code={'import { PreviewCard, PreviewCardTrigger, PreviewCardPopup } from "@galaui/react";'} />
