# Progress

Displays an indicator showing the completion progress of a task, typically displayed as a progress bar. Built on Base UI Progress primitives.

<div className="flex flex-wrap items-center gap-2 my-4">
  <Badge variant="outline" className="font-mono text-[11px]">@base-ui/react</Badge>
  <Badge variant="secondary" className="font-mono text-[11px]">WAI-ARIA Progressbar</Badge>
</div>

## Import

<CodeBlock language="tsx" code={'import { Progress, ProgressTrack, ProgressIndicator, ProgressLabel, ProgressValue } from "@galaui/react";'} />

## Example

<ComponentPreview
