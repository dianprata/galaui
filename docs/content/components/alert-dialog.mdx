# Alert Dialog

A modal confirmation prompt for critical, irreversible, or destructive actions that requires explicit confirmation. Built on Base UI AlertDialog with focus trapping.

<div className="flex flex-wrap items-center gap-2 my-4">

  <Badge variant="secondary" className="font-mono text-[11px]">Focus Trap</Badge>
