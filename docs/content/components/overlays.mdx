## Component Anatomy

Overview of exported subcomponents:

### Tooltip Parts
| Component | Role |
| :--- | :--- |
| `Tooltip` | Root container managing open/close hover timers. |
| `TooltipTrigger` | The anchor element that receives pointer and keyboard focus. |
| `TooltipPopup` | The animated floating tooltip card. |

### Popover Parts
| Component | Role |
| :--- | :--- |
| `Popover` | Root state controller for the popover surface. |
| `PopoverTrigger` | Button element that toggles visibility on click. |
| `PopoverPopup` | Floating surface container with elevation and arrow alignment. |
| `PopoverTitle` | Accessible title for assistive technologies. |
| `PopoverDescription` | Accessible description text. |
