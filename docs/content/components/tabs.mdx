# Tabs

A set of layered sections of content—known as tab panels—that are displayed one at a time. Powered by Base UI with animated selection indicators.

## Import

<CodeBlock language="tsx" code={'import { Tabs, TabsList, TabsTab, TabsPanel } from "@galaui/react";'} />
