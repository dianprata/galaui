# Toggle & Toggle Group

A two-state button that can be either on or off, or a group of segmented toggle buttons for single or multiple selection.

<div className="flex flex-wrap items-center gap-2 my-4">
  <Badge variant="outline" className="font-mono text-[11px]">@base-ui/react</Badge>
  <Badge variant="secondary" className="font-mono text-[11px]">Segmented Controls</Badge>
</div>

<CodeBlock language="tsx" code={'import { Toggle, ToggleGroup, ToggleGroupItem } from "@galaui/react";'} />
