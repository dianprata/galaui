# Toast

A succinct notification that floats temporarily over the screen to communicate quick feedback. Built on Base UI Toast with auto-dismiss and swipe gestures.

<div className="flex flex-wrap items-center gap-2 my-4">

  <Badge variant="secondary" className="font-mono text-[11px]">Auto Dismiss</Badge>
</div>

## Import

<CodeBlock language="tsx" code={'import { Toaster, toast } from "@galaui/react";'} />

## Setup

Mount the `<Toaster />` component once in your root application layout.

<CodeBlock language="tsx" code={'export default function App() {\n  return (\n    <>\n      <Toaster />\n      <MainApp />\n    </>\n  );\n}'} />

## Async Promise

Use `toast.promise()` to automatically manage pending, success, and error states of an async operation.

<ComponentPreview

## Outside React Components (Standalone Functions)

Because `toast` is an imperative singleton manager, you can trigger notifications directly from standard JavaScript/TypeScript functions, API interceptors, or state managers outside the React component lifecycle without needing hooks.

<CodeBlock language="tsx" code={'// api-client.ts (plain TypeScript file - no React hooks required)\nimport { toast } from "@galaui/react";\n\nexport async function syncUserData(userId: string) {\n  try {\n    const res = await fetch(`/api/users/${userId}/sync`, { method: "POST" });\n    if (!res.ok) throw new Error("Sync failed");\n    toast.success("User synced", "All records up to date.");\n  } catch (error) {\n    toast.error("Sync error", "Please check your network connection.");\n  }\n}'} />

## `toast.show` vs `toast.add`

Both methods create notifications, but they cater to different ergonomic preferences:

* **`toast.show(title, description?, options?)`** (Convenience Shorthand):
  Accepts positional arguments (`title` first, `description` second) so you do not have to write an object wrapper for simple messages. Shorthands like `toast.success()`, `toast.error()`, `toast.warning()`, `toast.info()`, and `toast.loading()` share this signature.

* **`toast.add(options)`** (Structured Options Object):
  The native Base UI manager method that receives a single configuration object. Ideal when you have dynamic payload objects, event data, or need to specify multiple properties at once.

<CodeBlock language="tsx" code={'import { toast } from "@galaui/react";\n\n// 1. toast.show - quick positional arguments\ntoast.show("Profile updated", "Your preferences have been saved.");\ntoast.success("Deployment ready", "Production build passed all checks.");\n\n// 2. toast.add - single structured configuration object\ntoast.add({\n  title: "Profile updated",\n  description: "Your preferences have been saved.",\n  type: "success",\n  timeout: 5000,\n  actionProps: {\n    children: "Undo",\n    onClick: () => handleUndo(),\n  },\n});'} />
