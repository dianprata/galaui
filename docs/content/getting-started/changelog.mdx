## v0.1.3

<div className="flex items-center gap-2 text-xs text-muted-foreground mb-6 not-prose">

  <span>•</span>

### 🚀 Highlights (v0.1.3)

Major expansion of the component catalog to 47 components, introduction of new form & toolbar primitives, and automated TypeScript API reference documentation.

### ✨ New Components

- **Combobox** — Advanced autocomplete and search selection primitive supporting single-select, multi-select chip layout, virtualized lists, and keyboard navigation.
- **Toolbar** — Accessible action bar and formatting container with grouped buttons, toggles, and separators.
- **Form** — Context-aware form provider integrating validation state with accessible field controls.
- **Label** — Accessible form label primitive with indicator bindings.

### 🎨 Component Enhancements

- **Toggle & ToggleGroup**:
  - Added `icon-sm` (28px) and `icon-lg` (36px) size variants.
  - Enabled item-level `size` and `variant` overrides inside `ToggleGroup`.
- **Combobox Polish**:
  - Implemented automatic item highlighting (`autoHighlight`) on keyboard focus.
  - Added responsive flex-wrap chips container for multi-select mode.
  - Fixed empty state indicator padding when filtered items are present.
- **Field & Fieldset**:
  - Refined validation message association and ARIA describedby attributes.
  - Added `Updated` badge to documentation.

### 📖 Documentation Engine

- **Automated Props & API Reference**:
  - Built TypeScript Compiler API extractor to parse props, types, default values, and JSDoc annotations directly from source files.
  - Added interactive `<PropsTable />` and `<ApiReference />` components with real-time property filtering and multi-subcomponent tabs.
- **Changelog**:
  - Added dedicated version changelog tracking release milestones.
- **Navigation Polish**:
  - Added component status badges (`New`, `Updated`) across sidebar and command palette search.

### 🎉 Initial Release of @galaui/react

- **Base UI Foundations**: 35+ accessible, unstyled primitives adhering strictly to WAI-ARIA authoring practices.
- **Tailwind CSS v4 Native**: Modern zero-config CSS architecture powered by pure CSS custom properties.
- **Complete Token System**:
  - Refined Zinc neutral ramps (`zinc-0` through `zinc-1000`).
  - Electric Cobalt brand focus (`brand-50` through `brand-950`).
  - Semantic status colors (`destructive`, `success`, `warning`, `info`).
  - Standardized corner radii and component sizing scale (`xs`, `sm`, `default`, `md`, `lg`).
