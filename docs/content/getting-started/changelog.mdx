### 🚀 Highlights (v0.1.6)

Unified release pipeline combining npm library publication with automated Cloudflare Pages documentation deployment, multi-branch CI testing covering `main` and `develop`, and zero-dependency native ESM script runtime.

### 🤖 CI/CD & Workflow Modernization

- **Unified Release Pipeline (`release.yml`)**:
  - Consolidated documentation deployment and npm publishing into a single atomic workflow.
  - Cloudflare Pages deployment executes sequentially only after the npm package successfully publishes (`needs: publish`).
  - Removed duplicate `deploy-pages.yml` workflow, eliminating redundant runner starts and race conditions.
- **Multi-Branch CI Pipeline (`ci.yml`)**:
  - Configured CI checks to validate all pull requests and pushes across both `main` and `develop` branches.
  - Keeps daily development and feature merges completely isolated from production releases.
- **Native ESM API Generator (`scripts/generate-api-docs.mjs`)**:
  - Refactored API documentation generation script to native ESM format.
  - Eliminated the `--experimental-strip-types` runtime flag for clean, universal Node.js compatibility across all environments.
- **npm Publish Idempotency**:
  - Added proactive version availability checks (`npm view`) before publishing to prevent HTTP 409 Conflict errors.

## v0.1.4

<div className="flex items-center gap-2 text-xs text-muted-foreground mb-6 not-prose">
  <span className="font-semibold text-foreground">September 7, 2026</span>
</div>

### 🚀 Highlights (v0.1.4)

Introduction of the automated TypeScript API reference documentation engine, interactive PropsTable with real-time filtering, dedicated Changelog tracker, and compiler-level Remark AST unwrap plugin for clean MDX component rendering.

### 📖 Documentation Engine

- **Automated Props & API Reference**:
  - Built TypeScript Compiler API extractor to parse props, types, default values, and JSDoc annotations directly from component source files.
  - Added `<PropsTable />` and `<ApiReference />` components with real-time property filtering and multi-subcomponent tabs.
  - Embedded across all 45+ component documentation pages.
- **Changelog Page**:
  - Added dedicated version changelog tracking release milestones from `v0.1.0` through `v0.1.4`.
  - Direct navbar shortcut from the version badge to the changelog page.
- **Table of Contents Polish**:
  - Added automatic heading ID deduplication to prevent React key collision warnings.

### ⚙️ Compiler & DX Polish

- **Remark AST Plugin (`remarkUnwrapComponentChildren`)**:
  - Intercepts AST nodes at the compiler level to unwrap synthetic paragraph blocks created by MDX inside JSX components.
  - Eliminates unwanted style and margin overrides inside `<Button>`, `<AlertDescription>`, and all JSX component elements.
