# Installation

Install `@galaui/react` and its peer dependencies into your React project.

## 1. Package Installation

Install via your preferred package manager:

### npm
<CodeBlock language="bash" code="npm install @galaui/react" />

### pnpm
<CodeBlock language="bash" code="pnpm add @galaui/react" />

### yarn
<CodeBlock language="bash" code="yarn add @galaui/react" />

### bun
<CodeBlock language="bash" code="bun add @galaui/react" />

---

## 2. Import Stylesheet

GalaUI includes all base styles and Tailwind CSS v4 design tokens in `@galaui/react/styles.css`. Import it at the root of your application (e.g. `main.tsx`, `App.tsx`, or Next.js `app/layout.tsx`):

<CodeBlock
  language="tsx"
  code={'import "@galaui/react/styles.css";\nimport React from "react";\nimport ReactDOM from "react-dom/client";\nimport App from "./App";\n\nReactDOM.createRoot(document.getElementById("root")!).render(<App />);'}
/>

---
