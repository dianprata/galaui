# Installation

Install `@galaui/react` and its peer dependencies into your React project.

## 1. Package Installation

Select your package manager to install the core package:

<Tabs defaultValue="npm" className="my-6">
  <TabsList>
    <TabsTab value="npm">npm</TabsTab>
    <TabsTab value="pnpm">pnpm</TabsTab>

    <TabsTab value="bun">bun</TabsTab>
  </TabsList>

  <TabsPanel value="npm">
    <CodeBlock language="bash" code="npm install @galaui/react" />
  </TabsPanel>

  <TabsPanel value="pnpm">
    <CodeBlock language="bash" code="pnpm add @galaui/react" />
  </TabsPanel>

  <TabsPanel value="yarn">
    <CodeBlock language="bash" code="yarn add @galaui/react" />
  </TabsPanel>

  <TabsPanel value="bun">
    <CodeBlock language="bash" code="bun add @galaui/react" />
  </TabsPanel>
</Tabs>

## 2. Import Stylesheet

GalaUI includes all base styles and Tailwind CSS v4 design tokens in `@galaui/react/styles.css`. Import it at the root of your application (such as `main.tsx`, `App.tsx`, or Next.js `app/layout.tsx`):

<CodeBlock
  language="tsx"
  filename="main.tsx"
  code={'import "@galaui/react/styles.css";\nimport { StrictMode } from "react";\nimport ReactDOM from "react-dom/client";\nimport App from "./App";\n\nReactDOM.createRoot(document.getElementById("root")!).render(\n  <StrictMode>\n    <App />\n  </StrictMode>\n);'}
/>
